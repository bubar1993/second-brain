- Dalla sessione principale RemoteTrigger funziona (13.10.2026 sera): get → modifica del prompt in un file → update con il prompt intero (token compreso, resta solo nella chiamata) → get di nuovo e confronto col file (deve essere identico). Fatto così per "Bozze mail Ceramex" ore piene e weekend.
